# Experiments

This directory stores research experiment plans and results.

Each experiment should answer one question. Avoid mega-experiments that change five variables at once.

## Experiment lifecycle

```text
Plan -> Run -> Analyze -> Decide -> Update docs
```

## Required sections

Each experiment report should include:

- research question,
- hypothesis,
- dataset,
- configuration,
- metrics,
- results,
- failure cases,
- decision,
- next action.
