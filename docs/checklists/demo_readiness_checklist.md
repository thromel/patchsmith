# Demo Readiness Checklist

## Demo flow

- [ ] Demo issue is selected.
- [ ] Repository setup is reliable.
- [ ] Run completes within acceptable time.
- [ ] Retrieved context is interesting and understandable.
- [ ] Final patch is readable.
- [ ] Tests show meaningful evidence.
- [ ] Failure and retry behavior is available if useful.

## Visual assets

- [ ] Architecture diagram.
- [ ] Run timeline screenshot.
- [ ] Retrieved context screenshot.
- [ ] Diff screenshot.
- [ ] Evaluation table screenshot.

## Narrative

- [ ] Problem statement is clear.
- [ ] Differentiation from generic chatbots is clear.
- [ ] Research angle is clear.
- [ ] Safety angle is clear.
- [ ] Limitations are stated honestly.

## Public repo

- [ ] README is polished.
- [ ] Quickstart works.
- [ ] Example artifacts are included.
- [ ] Evaluation report exists.
- [ ] License choice is documented.
