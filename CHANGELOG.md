# Changelog

## 0.1.0 - Public R&D Preview

PatchSmith is now packaged as a public R&D preview for auditable repair-agent
runs.

### Added

- `patchsmith demo seeded-logic-bug`, a deterministic five-minute demo lane.
- `patchsmith inspect <run-dir-or-id>`, a concise artifact inspector for saved
  runs.
- Static sample artifact bundle under
  `docs/sample_artifacts/seeded_logic_bug/`.
- Public docs for artifact gallery, failure taxonomy, benchmark manifest schema,
  runtime fairness checks, and comparison positioning.
- MIT license.

### Claim Boundary

This release is an evidence-harness preview. It demonstrates controlled seeded
repair, artifact generation, sandbox validation, and local inspection. It does
not claim broad public-issue repair quality or superiority over coding agents.
